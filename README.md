# JK Portfolio

Personal IT portfolio built with HTML, CSS and JavaScript.

## Preview

Open `index.html` in a browser. No installation or build step is required.
Google Fonts requires an internet connection; system fonts are used as fallback.

## Features

- Responsive Thai portfolio with education, skills, experience and contact information
- Bigbike Showroom project link
- Scroll reveals, hover effects and subtle pointer-driven card motion
- Support for reduced-motion preferences

## Files

- `index.html`: content and structure
- `style.css`: layout, colors and animations
- `script.js`: scroll and interaction behavior
- `assets/`: portrait, logos and optional media from earlier designs
- `assets/logos/SOURCES.md`: logo sources
